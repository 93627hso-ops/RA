موقع بورتفوليو شخصي للمبرمج
============================

الملفات:
- index.html : محتوى الموقع
- style.css  : التصميم والألوان والتجاوب مع الموبايل
- script.js  : زر تبديل اللغة والقائمة

التشغيل:
1. فك ضغط الملف.
2. افتح مجلد programmer_portfolio.
3. افتح index.html بمتصفحك لمعاينة الموقع.

قبل النشر:
- غيّر كلمة Developer و Your Name إلى اسمك/اسمك البرمجي.
- عدّل قسم About Me والمهارات حتى تعكس خبرتك الحقيقية.
- استبدل روابط GitHub وDiscord والبريد بروابطك الفعلية.
- لا تضع توكنات أو كلمات مرور أو معلومات سرية داخل ملفات الموقع.

النشر المجاني:
يمكنك رفع الملفات إلى مستودع GitHub ثم تفعيل GitHub Pages من إعدادات المستودع.
